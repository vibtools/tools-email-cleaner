# Security Policy

## Reporting a Vulnerability

Vib Tools takes the security of our software seriously. If you discover a security vulnerability, please do not disclose it publicly.

Instead, please send a private report to:
**[support@vib.tools](mailto:support@vib.tools)**

We will acknowledge your report and work with you to understand and address the issue.

## Scope

This policy applies to the Email Data Cleaner tool and its associated repository.
