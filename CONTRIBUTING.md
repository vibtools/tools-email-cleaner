# Contributing to Email Data Cleaner

Thank you for your interest in contributing to Vib Tools!

## Public Project Principles

- This is a free and open-source project.
- We aim for practical, focused, and maintainable software.
- All processing must remain client-side (in-browser) for privacy.

## How to Contribute

1. **Find a Bug?** Open an issue on GitHub with clear reproduction steps.
2. **Feature Request?** Start a discussion or open an issue describing the use case.
3. **Pull Requests:**
   - Keep PRs focused on a single change.
   - Explain the problem and the fix clearly.
   - Respect the existing architecture and styling (Tailwind CSS).
   - Ensure code is documented and tested where appropriate.

## Security

If you discover a security vulnerability, please follow our [Security Policy](SECURITY.md).
